# Realiz Ascend

鬼畜リアル系サバイバルを実現する Minecraft 1.19.4 (Paper) プラグイン。
設計書に基づく全システムをゼロから実装した、運営介入を最小化する自走型サバイバルです。

## 主な機能

### 基本ルール
- 素手での伐採不可（工具必須・拳で木を殴るとダメージ）
- 水源バケツ不可（水流のみ）、水はプレイヤー近くでのみ流れる
- ブロック落下はホワイトリスト制（松明・看板は落ちない）
- 時限式松明（石炭で燃料延長）
- 全レシピは初クラフト時に自動アンロック

### 生存システム
- **季節**: 春/梅雨/夏/秋/冬（7日周期）。梅雨の作物腐敗・夏の畑乾燥・秋の霜・冬の成長停止
- **気温・体温**: バイオーム/標高/天気/周辺ブロックで気温変動。防具の保温値/遮熱値、冷たい食べ物で体温調整
- **栄養・水分**: カロリー/タンパク質/ビタミン/塩分の4要素。生水は煮沸かフィルターで浄化必須
- **出血・負傷**: 独立した血液ゲージ、部位ダメージ（頭/胴/脚）、感染、骨折
- **ストレス**: 顔文字表示。温度/暗闇/敵/睡眠不足で上昇、睡眠/食事/酒で低下
- **スタミナ・疲労**: 行動コスト、疲労でしか眠れない、睡眠負債
- **重量**: 重量オーバーで鈍足、重オーバーでジャンプ不可

### クラフト・装備
- **工具システム**: ハンマー/のこぎり/ノミ/針/包丁。ジャンル別にクラフト必須、耐久あり
- **医療アイテム**: 包帯/添え木/消毒液/抗生物質。じわじわ回復
- **調理台**: 専用GUIで料理を作成。ざっくりレシピ表示、パーフェクトレシピは秘密
- **保存食**: 燻製/塩漬け/乾燥で賞味期限が大幅延長、食品は腐る
- **罠**: スパイクトラップ/ベアトラップ/毒針トラップ
- **浄水フィルター**: 生水を清浄水に変換

### 進行・スキル
- **9系統のスキルツリー**: 持久力/筋力/耐性/代謝/料理/医療/建築/農業/戦闘（186アビリティ）
- 熟練度方式のレベル、スキルポイントでアビリティ解放、二択スキル
- **デスペナルティ**: リスポーン時ペナルティ、スキルレベル低下、高コストアビリティ自動解除
- **死体システム**: 死亡場所に死体が残り、仲間が回収可能
- **コーデックス**: 体験型チュートリアル、失敗から学ぶ

### 連携
- **BreweryX**: 醸造酒のアルコールでストレス低下・水分減少

## 必要環境
- Java 17
- Paper 1.19.4
- (任意) BreweryX

## インストール
1. `RealizAscend.jar` を `plugins/` に配置
2. サーバーを起動
3. ゲーム内で `/realiz info` で状態確認、`/realiz skill` でスキルメニュー

## コマンド
| コマンド | 説明 |
|---------|------|
| `/realiz` | ヘルプ表示 |
| `/realiz info` | 自分の状態を表示 |
| `/realiz codex` | コーデックスを開く |
| `/realiz skill` | スキルメニューを開く |
| `/realiz reset <player>` | プレイヤーデータをリセット (OP) |
| `/realiz reload` | 設定を再読み込み (OP) |

## ビルド
```bash
mvn clean package
```
生成物: `RealizAscend.jar`

> BreweryX連携を有効にしてビルドする場合、`BreweryX-3.4.10.jar` をローカルMavenリポジトリに登録してください:
> ```bash
> mvn install:install-file -Dfile=BreweryX-3.4.10.jar -DgroupId=com.dre -DartifactId=breweryx -Dversion=3.4.10 -Dpackaging=jar
> ```
